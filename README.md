# Strata

A clinical marker intelligence dashboard for early-warning signals in hospital admissions. Built on MIMIC-IV Clinical Demo data.

> **Demo only — not for clinical use.**

---

## What it does

Strata ingests MIMIC-IV admission, lab, and vitals data, computes abnormal marker summaries and an AKI risk score for each patient, then surfaces everything in a Streamlit dashboard with charts and explainable flags.

---

## Prerequisites

- Python 3.10+
- The MIMIC-IV Clinical Demo dataset (already included in `data/mimic-iv-demo/` — do **not** commit or share this folder)

---

## Setup

**1. Clone the repo**

```bash
git clone <repo-url>
cd strata-app
```

**2. Create a virtual environment and install dependencies**

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

---

## Running the demo

**Step 1 — Build the data pipeline**

This processes the raw MIMIC-IV files and writes output CSVs to `outputs/`.

```bash
python -m src.run_pipeline
```

You should see each step complete with a checkmark. Takes ~10–30 seconds.

**Step 2 — Launch the dashboard**

```bash
streamlit run src/app.py
```

Streamlit will open a browser tab automatically (usually at `http://localhost:8501`).

## Project structure

```
strata-app/
├── data/
│   └── mimic-iv-demo/       # Raw MIMIC-IV demo CSVs (not committed)
├── outputs/                 # Generated by run_pipeline (not committed)
├── src/
│   ├── run_pipeline.py      # Runs all build steps in order
│   ├── load_data.py         # Loads raw MIMIC-IV files
│   ├── build_cohort.py      # One row per hospital admission
│   ├── marker_config.py     # Clinical marker definitions and thresholds
│   ├── build_markers.py     # Extracts and flags abnormal markers
│   ├── aki_scoring.py       # AKI risk score (rule-based, explainable)
│   ├── build_dashboard_data.py  # Merges everything for the UI
│   └── app.py               # Streamlit dashboard
├── docs/
│   └── product_spec.md
└── requirements.txt
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError` | Make sure the venv is active and `pip install -r requirements.txt` ran without errors |
| `FileNotFoundError` on a CSV | Run `python -m src.run_pipeline` before launching the dashboard |
| Port 8501 already in use | Run `streamlit run src/app.py --server.port 8502` |
| Data folder missing | The `data/mimic-iv-demo/` folder is excluded from git — get it from the shared drive or Anthony |
